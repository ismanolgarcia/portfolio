#  Mi Portafolio 

Bienvenido a mi **portafolio personal**, un espacio donde presento mi trayectoria como **Ingeniero en Software** y mi pasión por el **desarrollo web moderno**.  

Aquí encontrarás información sobre mí, mis habilidades técnicas, y algunos de los proyectos en los que he trabajado o estoy desarrollando.

## Cómo ejecutar localmente

Si deseas clonar o probar el proyecto en tu entorno local:

```bash
git clone https://github.com/ismanolgarcia/portfolio.git
cd portfolio
npm install
npm run dev
```
